# 管理端（Admin Console）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 SmartCS-Agent 增加独立管理端（控制台/商品/订单/知识库/工单 5 模块），含 19 个 `/api/admin/*` 端点与 `admin.html` 前端入口，客户端一行不改。

**Architecture:** 后端在既有 FastAPI 应用内加一个 `app/api/admin/` 路由包（组级 `Depends(require_admin)`），前端在既有 Vite 工程内加第二个入口 `admin.html` + `src/admin/`，与客户端共享 `src/api/auth.js` 的 token 工具函数与同一份 Tailwind 配置。知识库上传走**两阶段**（`stage` 只落盘 / `commit` 走完整索引链路并以 SSE 推实时进度）。

**Tech Stack:** FastAPI 0.141 + SQLAlchemy 2.0 async + psycopg + PostgreSQL/pgvector；Vue 3 + Vite 6 + Tailwind 3 + ECharts 6。

## spec 内部不一致处的裁决（实施时以本节为准）

spec 经审计后仍留了 4 处自相矛盾，会让实施者卡住。逐条裁决如下，**全文其余部分均按此执行**：

### 裁决 1：进度事件的上限是 **99**，不是 100

- spec §5.7 的 `_emit` 写 `min(_pct, 100)`；而 §8.5 的验收断言写 **"最后一个 progress 事件 `<` 100（100 只出现在 `done` 事件里）"**。
- 两者不能同时成立——权重表（5+45+5+5+35+5）合计正好 100，`store` 阶段发完就是 100。
- **裁决：取 §8.5**（它是可执行的验收契约，§5.7 是实现示意）。`_emit` 改为 `min(_pct, 99)`。
- 语义也更干净：**100% = 已完成，只由 `done` 事件给出**；进度条在收尾写入阶段停在 99%。

### 裁决 2：`commit` 的 `user_id` 取自 **令牌**，不取自请求体

- spec §5.7 的实现代码里写了 `"user_id": str(payload.user_id)`，但 §5.9 的 `KnowledgeCommit` schema **根本没有 `user_id` 字段**，§6.4.5.2 的前端 `startCommit({md5, original_filename, description})` 也不传它。
- **裁决：`commit` 端点注入 `current_user: User = Depends(require_admin)`，用 `str(current_user.id)` 作为 `user_id`。**
- 理由：① 与 §5.9 / §6.4.5.2 两处口径一致（前端不加字段）；② 归属身份来自 JWT 而非请求体，不可伪造；③ `require_admin` 在组级依赖里已跑过一次，FastAPI 对同依赖同请求复用缓存，**不产生第二次查库**（spec §5.8 也是这么用它的）。
- 连带：`stage` 仍按 spec §5.7 收 `Form(user_id)`（该值只用于 stage 的重复预检响应，不写库）。两者都取"当前登录管理员的 id"，前端 stage 传 `me.id`、commit 传令牌，值一致。

### 裁决 3：`unstage` 用 glob 定位文件，不接受客户端回传路径

- spec §5.7 写 `DELETE /knowledge/stage/{md5}`，但没写怎么把 `{md5}` 映射回 `{md5}{ext}`（`unstage` 的请求里没有 `original_filename`，拿不到 `ext`）。
- **裁决：在 `_staging/` 下 glob `{md5}.*` 并删除全部命中。** 不引入"客户端回传扩展名"——那是个路径注入面（spec §5.7 自己就强调过"绝不接受客户端回传任意路径"）。
- `md5` 先用 `^[0-9a-f]{32}$` 正则校验再拼路径。

### 裁决 4：`documents.status='disabled'` 的 tooltip 文案

- spec §12-5 要求"前端「状态」列做 tooltip 注明"停用不影响检索，但没给文案。
- **裁决：`title="停用仅影响管理端展示，智能客服仍会检索到该文档（已知限制）"`。** 写在 KnowledgeView 的状态列 `<th>` 上，不做成动态 tooltip 组件。

```python
@router.get("/stats")

    async def count(model, *conds):
        stmt = select(func.count()).select_from(model)
        if conds:
            stmt = stmt.where(*conds)
        return (await db.execute(stmt)).scalar()
```

- [ ] **Step 2: 写 `GET /charts`**。四张图；**日期基准必须 UTC**，**必须左连接补齐空日**（spec §5.4(a)(b)）：

```python
from datetime import datetime, time, timedelta, timezone

ORDER_STATUSES = ["处理中", "已发货", "已送达"]
TICKET_STATUSES = ["待处理", "已解决"]


@router.get("/charts")
async def get_charts(days: int = Query(7, ge=1, le=30), db: AsyncSession = Depends(get_db)):
    """四张图的数据(days 默认 7,范围 1-30)。"""
    # (a) 日期轴统一 UTC:库时区 Etc/UTC,orders.order_date 也由种子按 UTC 写
    today = datetime.now(timezone.utc).date()
    days_list = [today - timedelta(days=i) for i in range(days - 1, -1, -1)]
    labels = [d.strftime("%m-%d") for d in days_list]
    start_date = days_list[0]

    # (b) 分组计数后左连接到日期轴,缺失日补 0(否则 X 轴跳日)
    order_rows = (await db.execute(
        select(Order.order_date, func.count())
        .where(Order.order_date >= start_date)
        .group_by(Order.order_date)
    )).all()
    order_map = {r[0]: r[1] for r in order_rows}

    conv_rows = (await db.execute(
        select(func.date(Conversation.created_at), func.count())
        .where(Conversation.created_at >= datetime.combine(start_date, time.min))
        .group_by(func.date(Conversation.created_at))
    )).all()
    conv_map = {r[0]: r[1] for r in conv_rows}

    order_status_map = dict((await db.execute(
        select(Order.status, func.count()).group_by(Order.status)
    )).all())
    ticket_status_map = dict((await db.execute(
        select(Ticket.status, func.count()).group_by(Ticket.status)
    )).all())

    return {
        "trend": {
            "days": labels,
            "orders": [order_map.get(d, 0) for d in days_list],
            "conversations": [conv_map.get(d, 0) for d in days_list],
        },
        # 固定顺序,与前端图例颜色绑定(§6.6);计数为 0 也要返回该项
        "order_status": [{"name": s, "value": order_status_map.get(s, 0)} for s in ORDER_STATUSES],
        "ticket_status": [{"name": s, "value": ticket_status_map.get(s, 0)} for s in TICKET_STATUSES],
        "product_category": [
            {"name": r[0], "value": r[1]}
            for r in (await db.execute(
                select(ProductPriceStock.category, func.count())
                .group_by(ProductPriceStock.category)
                .order_by(func.count().desc())
            )).all()
        ],
    }
```

```python
    total = (len(texts) + batch_size - 1) // batch_size
    for idx, i in enumerate(range(0, len(texts), batch_size)):
        batch = texts[i : i + batch_size]
        vecs = await _embed_with_retry(provider, batch)
        results.extend(vecs)
        if on_batch is not None:
            await on_batch(idx + 1, total)      # ← 新增(默认 None 时行为不变)
    return results
```

```python
async def unstage_knowledge(md5: str):
    """撤销暂存:删掉落盘文件,不碰任何 DB。幂等(不存在也返回 200)。"""

            except OSError:
```
