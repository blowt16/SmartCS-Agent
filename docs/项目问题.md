# 项目问题记录

> 更新日期：2026-08-27（知识库动态信息入库 + 售后政策独立文档 + 口语化 query 检索测试）

## 一、检索召回问题

### 1. 商品名 + 售后主题混合 query 召回失败
- **现象**："我要退货小米智能门锁pro" 召回商品块（XMZNMS04LM 等）而非退货政策块，政策块掉出 top-3
- **根因**：query 含商品名时，商品块（含商品名）在 BM25/向量两路竞争中天然占优，reranker 精排后政策块出局
- **方向**：售后 Agent 接入时配合实体识别（识别商品名 → 定向查该商品售后政策 + 通用政策）

### 2. 同品牌多型号竞争导致错召回
- **现象**："米家智能晾衣机Pro怎么升降的" top-2 召回无关乐歌块；"米家智能窗帘2支持小爱控制吗" 被窗帘1S 顶掉，窗帘2 自己的块未进 top-3
- **根因**：query 命中品牌/品类泛化词时，同品牌多型号块互相竞争
- **方向**：检索后按商品名二次过滤 / 实体识别归一化

### 3. 自然内容下商品文档跨商品混合块（66%）
- **现象**：500 字符贪心切分下，33 块中 22 块跨商品（相邻商品内容拼一块），reranker 相关度被稀释（实测 E30、鹿客x1 等型号召回不稳定）
- **背景**：内容量随机是生产环境常态，**已明确不做内容约束规避**（450 字符约束已移除）
- **方向**：索引管道切分策略演进——章节感知切分（尊重 H 标题边界，块 = 商品/章节单元）

### 4. 政策文档自然内容章节合并
- **现象**：售后政策文档 1401 字符 → 4 块，"价格保护+售后流程"等章节被贪心合并
- **影响**：B3"按摩椅坏了怎么维修" 命中政策但章节错位（价格保护而非售后流程）
- **方向**：同问题 3，切分策略演进

## 二、链路问题

### 5. 纯售后意图 query 不检索知识库
- **现象**：真实意图识别链路中，"这个芝华仕沙发怎么退货" 判定为 aftersale → 走 `aftersale_placeholder` 占位节点（静态话术），**不触发 RAG 检索**
- **影响**：售后政策文档知识库就位，但纯售后意图 query 拿不到答案
- **方向**：售后 Agent 接入占位节点（替换 aftersale_placeholder），让售后意图 query 检索知识库 + 商品动态表

### 6. 意图识别对"商品参数级售后咨询"的归类依赖 LLM
- **现象**："芝华仕50611B沙发金架保用几年" 被判定为 presale（售前）→ 走 RAG 可答；同类售后咨询归类不稳定
- **影响**：同类问题可能被路由到售后占位节点而不可答
- **方向**：售后 Agent 接入后统一收敛

## 三、测试问题

### 7. 既有测试失败：test_bm25_retriever.py::test_bm25_recalls_docs_with_partial_terms
