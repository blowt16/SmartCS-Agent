SmartCS-Agent 系统运行流程图集

9 张交互式流程图，开发视角（含真实文件、函数、接口与表名）。每张可独立打开，支持缩放、搜索与明暗主题切换。

主线 A · 客服对话

  • 客服对话端到端主路径workflow
    一条主线看完全流程：用户提问 → HTTP 入口 → 入口指代消解 → 意图识别与路由 → 售前导购 → SSE 流式出口。
  • 对话业务分派与出口workflow
    路由之后扇出到五类业务落点，再汇聚到 SSE 出口。含语义缓存「当前未启用」与出口闸门的标注。
  • 售前导购编排流程workflow
    create_research_plan 容器 → TimeoutGuard 30s → multi_tool 子图（planner 任务分解 → Send 并行派发 → customer_tools 检索 → summarize → final_answer）。
  • 售前检索管线workflow
    RAGRetrieverService 混合检索：向量 ∥ BM25 → RRF 融合 → Reranker 精排，加 RAG 门控动态补全；含两个未接入 @tool 的虚线标注。
  • 追问与意图澄清workflow
    clarify_node 的提示词组装、历史压缩、LLM 生成与静态模板兜底，以及澄清后回到识别节点的虚线反馈环。
  • 意图识别与路由决策workflow
    ScopeGuard 关键词预检 → Router 双维（type + risk）结构化输出 → route_query 优先级判定 → 8 个落点。

主线 B · 管理端

  • 管理端端到端运行流程workflow
    前端四态鉴权闸门 → require_admin 组级依赖 → 控制台 / 商品 / 订单 / 知识库 / 工单五大模块，共 19 个端点。
  • 知识库上传与索引管道dataflow
    暂存校验 → 解析 → 清洗切块 → 向量化 → 入库，五阶段对齐索引进度权重，含 SSE 进度回传通道。
  • 订单状态生命周期lifecycle
    处理中 → 已发货 → 已送达 → 已签收，含签收日期绑定约束，以及代码中真实存在的「无状态机约束」任意跳转。
